### Converter Use:
This is just for protein sequences, so add ions, ligands, DNA yourself.


### In AlphaFold3 Website:

Upload the JSON file and it will save however many drafts you uploaded.
BUT
It won't run automatically, so you need to select it, then it will populate the sequence box(es) and then you have to press the RUN button.
Fortunately, the naming remains that same so you don't have to do more than that.
