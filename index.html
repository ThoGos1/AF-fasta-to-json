FASTA to AlphaFold3 JSON

Convert a multi-sequence protein FASTA file into an AlphaFold Server job file. Everything runs in your browser, and nothing is uploaded.

1. Input FASTA

Drop a .fasta / .fa / .txt file here, or click to choose one

2. Options

3. Add to every job (optional)

Ligands, ions, DNA, RNA or extra protein chains added to each job after its own protein chain. In single-job (complex) mode they are added once.

4. Result
